Course Reflection

In Essential Skills & Digital Literacy I enjoyed learning about how to create folders to organize my documents and files and learning to save files to different locations. I found it most challenging to save files that were not created on my OneDrive to my OneDrive but handled it by practicing it and eventually got it. I can use these skills when doing schoolwork and in the future a job but would like to get more efficient at saving files to different locations. In Digital Media I learned to create posters in Canva, and edit images, but enjoyed using formulas in Excel the most. It was challenging to make more complex formulas in Excel (Triangle Classification Challenge), and I handled it by trying different things and searching up formulas if I was still stuck. I can use these skills in the future when creating budgets, designing advertisements, creating resumes, and would like to learn to use more advanced photo editing tools.

The second half of the class had larger projects like game development and building a webpage. In Game Development, I learned to create a simple space shooter game in Gdevelop and enjoyed adding powerups like a shield and health reset the most because it made the game more engaging. I found adding a high score system was the most challenging, but I handled it by using Google Search and experimenting with storage actions. These skills could be useful when creating a small game and I would like to learn about making a more interesting enemy that can fly in different directions. In Web Development, I learned to edit a simple website and enjoyed putting my favorite links and a cool image in it. These skills could be useful when running a business and creating a simple website to show products and sell online in the future, but it would be useful to learn more about the code that goes into a website. ICT 8 really helped me improve my computer literacy and gave me skills that will help me at school and at jobs.
