Course Reflection

In unit 1 I learned how to download, extract, save, and manage my files, which was very useful because it’s very important to know where you saved your files and how to access them. Although, it was a challenge to learn how to download and extract files from different sites because sometimes I couldn’t understand what I was supposed to do, and other times it wasn’t saving to my H Drive! In unit 2 I learned how to create data tables, graphs, and distribute survey information into Excel, which is useful because it allowed me to keep all my information in one table, and I could create graphs comparing all my data if I needed to. One challenge I had when creating the tables was when I had to put in formulas such as A2+B2=C2, because it was a new tool I was working with and it was pretty confusing. In unit 3 I learned how to create a working video which was super fun and beneficial to help with my coding skills. One challenge that I faced when I was making my video game was when I created a UFO boss to enter my game. It was a challenge because there were no step-by-step instructions telling me how to, I had to go based on my other enemy and my personal knowledge, which I found difficult. In unit 4 In ICT 8 I enjoyed making and creating the space shooter game the most. I enjoyed it because it was very fun to test, play, and accomplish my very own game. It was fun to see how these certain types of games are made, and it allowed my imagination to create different enemies and designs. I would like to learn more about creating video games because it was a super fun project, probably my most fun one to do, and it can help me with so many skills. It can help me with my coding skills, overcome issues, and being able to cope when things get difficult. I would use a ton of information that I have learned in this class in the future. I would use my knowledge from unit 1 to save files and manage them in a clean H Drive, so I know where I saved my files and how I can access them. I would use my knowledge from unit 2 to have all my data in tidy tables helping me to compare information when needed. I would use my knowledge from unit 3 to be able to code and create different games for different scenarios. And finally, I would use my knowledge from unit 4
