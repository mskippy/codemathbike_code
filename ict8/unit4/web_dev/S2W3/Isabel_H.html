Course Reflection

In essential skills and literacy, I enjoyed organizng all my folders because I've always enjoyed organizing anything I got my hands on. I found making the how to posters slightly challenging because sometimes I had trouble explaining the next step. I got over this challenge by thinking through everything I had done before the certain step, and going through the process again. I would like to learn more about extracting ZIP files because I found it interesting. In the future I can use the skills I learned in this unit when I'm organzing my files on my computer. In digital media I enjoyed creating the about me posters because I was able to add whatever I wanted and customize it. A challenge I had was when we graphed data on the excel sheets. In the beginning I simply didn't understand so I had to ask for help. After this everything else went smoothly. I would like to learn more about photo editing because I'm interested in photography, so I found editing images fun. I could use the skills I learned in this unit in the future when I'm editing images or creating digital posters for marketing. In game development I enjoyed creating the video game because I liked how you need to really think when you do something wrong so you can fix the mistake. I found adding extensions like adding a get ready screen or a game over screen really challenging, specifically when I didn't have much time to attempt to build one. I would like to learn more about coding in general because I found it fun and it suprisingly wasn't too complicated. I could use these skills in the future when I am coding different things with my dad. In our last unit, web development, I enjoyed customizing my web page to what I wanted it to be. If I'm being honest, I didn't really find this unit challenging as I found it pretty straight forward. I would like to learn more about writing code so I could build things from scratch. I could use the skills I learned in this unit when I'm creating websites or writing code in different settings.
