Course Reflection

In ICT-8 I’ve learned lots about so many different topics, working on my skills and understanding around technology. My favorite topic we covered was probably Digital Media, because I really enjoyed making different designs and customizing things to different color schemes, based on how I liked the look of it. I really enjoyed making the poster on Canva. The part I found the most challenging In Digital Media was when we had to use the “magic media” feature on Canva to AI to generate an image of ourselves, since it was really hard to give it the right instructions to get an actually accurate image. I would like to learn more about that in the future, on how to use AI more efficiently as a tool for different projects and applications. Game and Web development had a lot of step-by-step instructions to help us know where to start and did tell us a lot about what to do, but it did still really help me have a better understanding on the workings of video games and all the different layers and code that goes into making a website. When it came to Essential skills for things as simple as organizing folders, it was a little surprising to me, just how many things that were out of place and unorganized. This topic really helped me learn how to keep my work stored so I can find it easily again in the future. -Keira.T
