    Course Reflection

    By: Ryu B

    In ICT 8 we had 4 units, here is my reflection on all of them. In our Essential Skills and Digital Literacy unit we learned how to extract zip files, make folders in OneDrive and our H Drive, how to save to H Drive, how to save to OneDrive, and we even learned about some of the computer parts when we did our web quest. I enjoyed learning how to extract a zip file as I had never even heard of a zip file. I would like to learn more about the components of a computer and I think all the skills I learned in this unit will be helpful to me while I am in high school. In our Digital Media I learned how to make a poster with Canva, how to use the built-in Canva AI, Canva elements, and how to use the magic eraser on Canva to get rid of photobombers. I found trying to use the magic eraser was the hardest part of the unit because every time I tried to erase something it just made that area of the image blurry although in the future, I would enjoy learning how to use other image editing platforms. I think this unit will be helpful when I am making presentations in Canva. In our Game development unit, we learned how to use GDevelop to make a basic space shooter game. One thing I found hard or challenging in this unit is trying to keep track of all the conditions and actions. In the future, I would like to learn how to use other game development platforms or even use GDevelop to make a better and more interesting game. I may use what I learned in this unit in the future I decide to try making a game on any game platform. In our Web Development unit (our current unit) I have learned how to use VS Code and how to add links, use buttons, change text, and change and add images. The hardest thing in this unit was changing the image as most of the time my link did not work. I would like to learn how to make a website from scratch with no template. I may use the skills I used in this unit if any of the future projects include making a website in the future. To conclude ICT 8 was a fun class that helped me learn many thing about The essential skills for OneDrive and HDrive, Canva, GDevelop, and VSCode.
