Course Reflection

In this course, I learned a lot about saving files properly, using diferent applications like Canva, Excel, GDevelop, and VS code, coding, and web development. In Unit 1, I learned about properly saving files to OneDrive and the H Drive. My favourite part about this unit was creating all of the folders, I enjoyed naming and organizing all of my subjects and adding a different colour for each folder. One thing that was challenging for me in this unit was unzipping files, as it was a bit harder to remember than just saving a file. I would like to learn more about the features in the H drive, because there are a lot of helpful ones that I could use in the future. I will use what I learned in this unit for the rest of my school career and beyond, as it is very important to keep your files organized, eepecially in upcoming grades. In unit 2, I learned about designing in Canva, using Excel, and editing images. My favourite part was editing photos in Canva, I loved exploring the features I hadn't used before, but I found Excel challenging because it was completely new to me. I would like to learn more about Excel, although I know that what I learned will help me a lot in the future, to create charts, tables, and spreadsheets. In Unit 3, I learned about game development, and my favourite part was adding my own features to the game to make it feel more complex. Although I liked adding my own features, it was also a challenge because I didn't have the instructions I had to code the other elements of the game. In Unit 4, I coded my own webpage with VS Code, my favourie part being changing the photo and colours to make it look more my own. The most challenging part for me was finding the right places to insert my text within the code, but I want to learn more about it so that I can eventually code things from scratch. I will also have some experience at making a webpage if I need to in the future! Overall, I enjoyed this course and learned a lot!

My goal for this course was to improve at typing and organizing my files within my computer, and I acheived that goal, by relearning how to place my hands properly on the keyboard, and creating differnt folders in my file explorer and OneDrive for different subjects.
