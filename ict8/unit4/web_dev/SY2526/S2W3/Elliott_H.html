Course Reflection

In ICT 8, I learned a lot about coding and digital media. In each unit, I learned skills that I hope and think that I will use in the future. First, I learned how to download files, and how to extract zipper files. One challenge of this unit was trying to make how to posters. The next unit focused on digital media, and I really enjoyed learning how to edit photos to make my Canva image. The hard part of this unit was trying to make an accurate AI image of myself for my About Me poster. The third and, in my opinion, the most fun unit was the game-making unit. I learned, enjoyed, and struggled in all aspects of this unit. My final assignment was making this website, which I learned how code works from. I did stuggle to figure how to start making it and get the template. All in all, I think I have learned a lot from this class in the past month, and I look forward to my next ADST rotation.
