    Course Reflection

    In ICT 8 we had four units, essential skills and digital literacy, digital media, game development, and web development. In essential skills and digital literacy, I learned how to extract zip files, how to save a file to h-drive, how to save a file to one drive, and how to create folders in one drive and h-drive. I enjoyed learning about how to save a file to H-drive most because it was most useful. I found extracting zip files most challenging because I could not find the right buttons. I would like to learn more about extracting, saving, and organizing so my computer experience is smoother. I might use what I learnt on my future school projects or in a future job position. In digital media, I learned how to edit photos and use Canva. I enjoyed designing my poster most because it gave me creative freedom. I found the Ai component most challenging because I don't particularly like supporting Ai so morally it was challenging. I would like to learn more about manual hand editing in photoshop. I might use these skills in future projects in classes or when I want to erase a photo bomber! In Game development I learned how to create a video game! The thing I enjoyed most was creating and playing my game. The most challenging part was coding and spelling. I would like to learn more about game design and development as a future creative career. I might use these skills in a future job in tech and game design. In web development, I learned how to personalize websites. The part I enjoyed most was customizing it and making it reflect me! The most challenging part was coding once again. I would like to learn more about web development and design. I could use this if I made a future art website!
