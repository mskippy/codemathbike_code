Course Reflection

This class has taught me many things about technology and will be useful in the future. While learning the essential skills, I learned how to properly handle files, assignments, and how to navigate OneDrive. These skills will help me in many other classes. A challenge I faced was saving files in the right places, but after some help, I managed. The digital media unit helped us express ourselves while learning about apps such as Canva and how to use them. A challenge in this unit was creating the AI images for our All About Me, but using the right prompts was a big help. The most fun unit was Game Development where we learned how to create our own game. I would like to know more about game making and how to advance further. Since game development was very new to me, the whole unit was challenging. But the step-by-step instructions helped make it easier. In web development, I learned how to make my own website and insert links for images. Overall, being in ICT has taught me many things and was a very fun class, with my favorite unit being Game Development.
