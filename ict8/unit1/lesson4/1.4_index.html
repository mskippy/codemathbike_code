Overview

Purpose: You have already learned these skills in Lessons 1.2 and 1.3. In this lesson, you will review what you know and show your understanding by creating clear How To posters.

Goal: If another Grade 8 student followed your poster, they should be able to do the task correctly.

Your Task

You will create How To posters in Microsoft Word for the following skills.

Required Posters (4 total)

  1. How to Save a File to OneDrive
  2. How to Save a File to the H: Drive
  3. How to Create Folders
    • Creating folders in OneDrive
    • Creating folders in the H: Drive
  4. How to Extract a ZIP File

These are all skills you have already practised. This assignment is about explaining clearly, not learning something new.

Poster Requirements

Each poster must include:

  • A clear title
  • Numbered step-by-step instructions
  • 2–3 screenshots you took yourself
  • Simple highlights (circle, arrow, or box)
  • A clean, easy-to-read layout
  • Your name on the poster

Tool

All posters must be created in Microsoft Word.

File Naming & Saving

Name your files like this:

  • 1.4_HowTo_SaveToOneDrive
  • 1.4_HowTo_SaveToHDrive
  • 1.4_HowTo_CreateFolders
  • 1.4_HowTo_ExtractZip

Save your work in:

H:\ICT 8\1. Essential Skills

Handing It In

  • Upload each poster as a separate file to the Teams assignment.
  • Double-check file names before clicking Hand In.

Extension

If you finish early, create one extra How To poster for a skill you think all ICT students should know.

Examples:

  • How to rename files properly
  • How to upload work to Teams
  • How to take a screenshot using the Snipping Tool
  • How to organize files for a project

Choose one skill and explain it clearly.
