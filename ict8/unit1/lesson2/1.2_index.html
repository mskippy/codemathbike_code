Lesson 1.2 — Essential Skills Studio: Managing Your Files

Today you’ll practise how to organize, save, move, and manage files the way you are expected to in ICT. You will complete the same task four times, but each file will start in a different place.

These skills will be used all year (Digital Media, Game Development, and Web Development).

Activity A — Organize Your Folders

Goal: Set up your ICT folder so you always know where your work belongs.

  1. Open OneDrive.
  2. Create this folder structure:
OneDrive └── Grade 8 └── ICT 8 └── 1. Essential Skills
  1. Open File Explorer.
  2. Confirm you can see the same folders in your OneDrive location.
All Lesson 1.2 files must be saved here:
OneDrive → Grade 8 → ICT 8 → 1. Essential Skills

Don’t continue until your folders are set up correctly.

Important Rule

Do not start typing in any file until you:

  • check where it is saved
  • move it to the correct folder
  • rename it
  • turn Autosave on

This is part of the learning.

Activity B — File Downloaded from the Website

Where this file comes from: the class website (using Microsoft Edge).

When you click a download link in Edge, a box appears with options like Open, Save, and Save As.

Choose ONE:

Option A — Save

  • Click Save
  • The file goes to Downloads
  • Move it to:
OneDrive → Grade 8 → ICT 8 → 1. Essential Skills

Option B — Save As

  • Click Save As
  • Choose:
OneDrive → Grade 8 → ICT 8 → 1. Essential Skills

This saves it to the right place right away.

Do NOT choose “Open” when downloading from a website.

  1. Download the file below.
Download: 1.2_Website_Download_Practice.docx
  1. Rename the file to: 1.2_File_Practice_[YourName]
  2. Open the file and complete all tasks inside it.

Activity C — File from a Teams Assignment

Where this file comes from: a Teams assignment attachment.

Important: Teams makes a copy for you, but it is not saved in your ICT folder.

You must move it before you start typing.

  1. Open the Word file from the Teams assignment.
  2. Do not start typing.
  3. Go to File → Save As.
  4. Save it to:
    OneDrive → Grade 8 → ICT 8 → 1. Essential Skills
  5. Rename it to:
    1.2_File_Practice_[YourName]
  6. Turn Autosave ON.
  7. Complete all tasks inside the document.

(Your teacher will provide this file inside Teams — there is no website download link for this one.)

Activity D — Shared File in Teams

Where this file comes from: Teams → Shared.

Shared files belong to the class. They are not your personal working copy.

Rule: Use Save a copy before you edit.

  1. Open the shared file in Teams → Shared.
  2. Choose Save a copy.
  3. Save the copy to:
    OneDrive → Grade 8 → ICT 8 → 1. Essential Skills
  4. Rename it to:
    1.2_File_Practice_[YourName]
  5. Complete all tasks inside the document.

(This file is provided in Teams — there is no website download link for this one.)

Activity E — Creating a New File

Where this file comes from: you create it in Word (blank document).

Rule: Save first, then work.

Autosave only works after the file is saved to OneDrive.

  1. Open Word.
  2. Create a new blank document.
  3. Immediately go to File → Save As.
  4. Save it to:
    OneDrive → Grade 8 → ICT 8 → 1. Essential Skills
  5. Name the file:
    1.2_New_File_Practice_[YourName]
  6. Turn Autosave ON.
  7. Complete the task inside your document.

Screenshot Reminder

Each document will ask you to include one screenshot as proof you saved the file correctly.

Your screenshot must show:

  • File Explorer
  • the file name
  • the file inside the correct folder

Shortcut: Windows + Shift + S (screenshot) → Ctrl + V (paste into Word).

Success Criteria

  • ☐ My folders are organized correctly
  • ☐ I completed all four file tasks
  • ☐ All files are saved in the correct folder
  • ☐ All files are renamed clearly
  • ☐ Autosave is ON
  • ☐ Each document includes a screenshot

Why This Matters

Good file management prevents lost work, makes submitting assignments easier, and prepares you for Digital Media, Game Development, and Web Development. These are essential ICT skills.
