Quick Reference

Your Folder Structure

You'll build the same folders in two places:

OneDrive → Grade 8 → ICT 8 → 1. Essential Skills

H: → Grade 8 → ICT 8 → 1. Essential Skills

  • OneDrive — Word documents and anything from Teams
  • H: drive — downloads, media and game files

New Folder

Right-click an empty space → New → Folder, or press Ctrl + Shift + N.

Unzip a .zip File

Right-click the .zip → Extract All → Extract.

Taking a Screenshot

Press Windows + Shift + S, then drag to select the area. It saves itself automatically to Pictures → Screenshots — no need to paste it anywhere right away.
