Overview

Today’s focus: You will learn how to organize, save, move, and manage files the way you are expected to in ICT.

You will complete the same task multiple times, but each file will start in a different place. This helps you understand how file behaviour changes depending on how the file was opened.

These skills will be used all year (Digital Media, Game Development, Web Development).

The Most Important Rule in ICT

Never start typing or editing until you:

  • check where the file is saved
  • move it to the correct folder if needed
  • rename it clearly
  • turn Autosave ON (when available)

This rule applies to every project you do this year.

Where Files Are Saved (This Explains Everything)

Not all files save to the same place. Where a file saves depends on how it is opened. Understanding this now will save you a lot of frustration later.

🖥️ When File Explorer Opens → H Drive

This usually happens when:

  • you download a file from a website
  • you export or download media
  • you choose Save As and browse folders

Files saved this way live on your H Drive (school network). This is normal and expected.

☁️ When Word Opens First → OneDrive

This usually happens when:

  • you open a file from Teams
  • you open Word and start a new document
  • Autosave is turned on

Files saved this way usually live in OneDrive.

✅ In ICT 8

Your work may be saved in OneDrive OR your H Drive. Both are OK.

What matters is that:

  • the file is saved on purpose
  • it is in your ICT folder
  • you can find it quickly
  • you can submit it correctly

Where this file comes from: the class website (using Microsoft Edge).

Activity C — File from a Teams Assignment

Where this file comes from: a Teams assignment attachment.

Important: Teams makes a copy for you, but it is not saved in your ICT folder. You must move it before you start typing.

  1. Open the Word file from the Teams assignment.
  2. Do not start typing.
  3. Go to File → Save As.
  4. Save it to: OneDrive → Grade 8 → ICT 8 → 1. Essential Skills
  5. Rename it to: 1.2_File_Practice_[YourName]
  6. Turn Autosave ON (when available).
  7. Complete all tasks inside the document.

Activity D — Shared File in Teams

Where this file comes from: Teams → Shared.

Rule: Shared files belong to the class. Use Save a copy before you edit.

  1. Open the shared file in Teams → Shared.
  2. Choose Save a copy.
  3. Save the copy to: OneDrive → Grade 8 → ICT 8 → 1. Essential Skills Web Quest
  4. Rename it clearly.
  5. Complete all tasks inside the document.
  6. Turn in your assignment on Teams under 1.2 Essential Skills WebQuest.

Activity E — Creating a New File

Where this file comes from: you create it in Word (blank document).

Rule: Save first, then work.

  1. Open Word.
  2. Create a new blank document.
  3. Immediately go to File → Save As.
  4. Save it to: OneDrive → Grade 8 → ICT 8 → 1. Essential Skills
  5. Name the file: 1.2_New_File_Practice_[YourName]
  6. Turn Autosave ON (when available).
  7. Complete the task inside your document.
