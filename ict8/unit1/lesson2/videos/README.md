# Lesson 1.2 — How-To Video Scripts

Silent screen recordings, 30–60 seconds each. Pause about 1 second after every click so students can follow. The **On-screen text** column is optional caption text to add while editing.

When a video is finished, save it in this folder with the filename shown. Then, in `../1.2_index.html`, uncomment that video's `<figure>` block and delete its "Video coming soon" placeholder.

Recording tips: Snipping Tool (Windows + Shift + R) or ScreenPal. Record just the window, not the whole screen. Zoom Edge and Word to about 125% so text stays readable when the video plays in the page.
