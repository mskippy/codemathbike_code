3) Fold an Origami Creation

Objective: Practice reading instructions carefully, following multi-step directions, and learning independently using online resources.

Choose an origami design to create. A paper crane is recommended, but you may choose another origami shape if you would like an extra challenge.

Why are we doing this?

  • Learn to read and follow directions carefully
  • Practice problem-solving when instructions are unclear
  • Compare different learning styles (video, diagrams, written instructions)
  • Build patience and attention to detail

Your Task

  1. Find an online resource (video, diagrams, or written instructions).
  2. Fold your origami creation independently or with a partner.
  3. If you get stuck, try a second resource before asking for help.
  4. Hand in your completed creation to your teacher.
  5. Move onto the next task

Suggested challenge: Start with an origami crane 🪽

4) Start Typing Practice

Objective: Build speed and accuracy using TypingClub.

  1. Go to TypingClub.
  2. Sign in using your school email; first name and last initial; and don't forget your password!
  3. Start with the placement test.
  4. Start typing for the rest of the class.
  5. You will start with typing at the begining of each class.

Tip: Use correct finger placement — accuracy first, then speed!
