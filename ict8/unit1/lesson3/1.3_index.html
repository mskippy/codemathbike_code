Overview

Today’s focus: You will learn how to download ZIP files, extract them, and move the extracted folders to the correct location on your H Drive.

You will repeat the process more than once so it becomes familiar. The goal is not speed — it’s being able to recognize ZIP files and know what to do with them.

Important Idea (Read This First)

Some downloads come as .zip files. A ZIP file is a compressed folder.

You cannot use the files inside a ZIP file until you extract it. Always extract first, then move the extracted folder to the correct place.

Activity A — Download a ZIP File (Guided)

  1. Go to this page: Space Shooter Redux (Kenney)
  2. Scroll until you see Download.
  3. Click Download.
  4. Choose Download without donation.
  5. When the browser asks what to do, choose Save.

Check: The file should download into your Downloads folder and end with .zip.

Activity B — Extract the ZIP File

  1. Open File Explorer.
  2. Go to Downloads.
  3. Find the ZIP file you downloaded.
  4. Right-click the ZIP file → choose Extract All.
  5. Click Extract.

Check: You should now see a regular folder (not zipped).

Activity C — Move the Extracted Folder to Your H Drive

  1. In Downloads, click the extracted folder once (the regular folder, not the .zip).
  2. Move the entire folder to your H Drive location:
H Drive
└── Grade 8
    └── ICT 8
        └── 3. Game Development

You can move the folder in either way:

  • Drag and drop (use the left navigation panel in File Explorer)
  • Cut and paste (Right-click → Cut, then Right-click in destination → Paste)

Check: The extracted folder should now be inside your H Drive folder.

Activity D — Check Your Work

Confirm the following before you continue:

  • ☐ The folder is not zipped
  • ☐ The folder is inside your H Drive → Grade 8 → ICT 8 → 3. Game Development
  • ☐ The folder name is visible
  • ☐ All files are still inside the folder

If something looks wrong, fix it now.

Activity E — Repeat with a ZIP File of Your Choice

  1. Go to: Kenney Asset Library
  2. Choose any asset pack you like.
  3. Download it using the same steps:
  • Click Download
  • Choose Download without donation
  • Choose Save

Then repeat:

  • Extract the ZIP file (Extract All)
  • Move the extracted folder to your H Drive folder

Goal: You should have two extracted folders saved in the correct place.
