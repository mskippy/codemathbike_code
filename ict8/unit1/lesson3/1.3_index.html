Overview

In many digital projects you will need to download files from the internet. Often these files are packaged inside a ZIP file.

Today you will learn how to:

  • download a ZIP file
  • extract the contents
  • move the folder to the correct location on your H Drive
  • explain the process in your own words

This is an important skill because many game assets, images, and project files are distributed as ZIP files.

Important Idea

A .zip file is a compressed folder.

It reduces the size of files so they can be downloaded faster and packaged together.

You cannot use files inside a ZIP file until it is extracted.

The correct workflow is: 


Download → Extract → Move to your folder

Activity A — Download a ZIP File

  1. Go to: Space Shooter Remastered
  2. Scroll until you see Download
  3. Select Download without donation
  4. When the browser asks what to do, choose Save

The file will download to your Downloads folder.

Check that the file ends with: 

.zip

Activity B — Extract the ZIP File

  1. Open File Explorer
  2. Go to your Downloads folder
  3. Find the ZIP file you downloaded
  4. Right-click the file
  5. Select Extract All
  6. Click Extract

You should now see a normal folder (not zipped).

Activity C — Move the Extracted Folder

Move the extracted folder to your ICT 8 folder: 


H Drive
└── Grade 8
    └── ICT 8
        └── 3. Game Development

You can move the folder by:

  • dragging and dropping
  • cut and paste

Make sure the extracted folder is inside this location.

Activity D — Repeat the Process

Now repeat the workflow with another asset pack.

  1. Go to the Kenney Asset Library
  2. Choose any asset pack you like
  3. Download the ZIP file
  4. Extract it
  5. Move the folder to your ICT 8 folder

By the end you should have two extracted folders.

You will now create a document that explains the process you just completed.

Open Microsoft Word and create a document called:
