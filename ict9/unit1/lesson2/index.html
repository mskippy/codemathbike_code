1.2 How Computers Think: Binary

Big idea: Every photo, song, game, and message the studio will ever make comes down to the same two things: on and off. Before you build anything this semester, it helps to know what's actually happening underneath.

Estimated time: 1–2 classes. This one moves at whatever pace makes sense — some classes will fly through it in a single sitting, others will want the extra day. Pace it however fits.

Activity A — What Is Binary?

Computer hardware is built from switches (transistors) that can only be in one of two states: on (1) or off (0). That's it — no in-between. Everything a computer does is some clever arrangement of those two states.

A single 1 or 0 is called a bit. Group 8 bits together and you get a byte — enough combinations to represent a letter, a small number, or one tiny piece of a picture.

Binary numbers work just like the decimal numbers you already know, except each place is worth a power of 2 instead of a power of 10:

1286432168421

To read a binary number, add up the place values wherever there's a 1. For example:

0 0 1 0 1 1 0 1 → 32 + 8 + 4 + 1 = 45

Try one yourself: what decimal number is 0 1 0 0 0 0 1 0?

64 + 2 = 66

Activity C — Decode the Studio's Secret Message

Text works the same way — every letter has a standard binary code (called ASCII). Capital letters start at 65 (A), so A = 0100 0001, B = 0100 0010, and so on in order through the alphabet.

Use the pattern above (or an ASCII table) to decode this message, one byte at a time:

0100 1000 0100 1001

Reveal the message

H I — 72 = H, 73 = I

This is exactly how a computer stores every word in this lesson, every chat message you send, and every line of code you'll write later this semester — just bytes, arranged in the right order.

Why This Matters

More bits means more possible values — each extra bit doubles how much you can represent. That's why an 8-bit byte can hold 256 different values (2⁸), why old 8-bit games looked blocky and had limited colours, and why a modern photo with millions of colours needs far more bits per pixel than a simple text file needs per letter.

Binary isn't a side topic — it's the layer underneath everything else in this course: your website's code, your game's save data, your AI conversations. All of it is bytes.
