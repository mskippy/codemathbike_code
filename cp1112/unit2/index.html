Unit 2 — Guided Project 1: Problem-Solving Application

Your first full trip through the design cycle, applied to a teacher-provided problem type — a calculator, quiz engine, or simple tracker. You choose from a short list, not fully open-ended yet. This is the first formally checkpoint-graded project, so the early periods spend extra time modelling what a strong checkpoint actually looks like.

What You'll Be Doing

Correct use of variables, conditionals, loops, functions, and lists; basic input validation; inline comments; test cases and hand-tracing used to debug.

If you're moving faster, it's the same project idea at a higher bar: your version must include at least one class, structured error handling (try/except), a debugger walkthrough in place of print debugging, and docstring documentation.

What You'll Produce

A working program, plus a design-cycle log: pitch → pseudocode → prototype → test → share.
