2C — Transfer It

Take what you know in Python and prove it works in a new language.

This Level Is for You If…

  • Python feels comfortable, and you're curious how other languages do the same things.
  • You finished Unit 1 without getting stuck on the core concepts.
  • You're up for learning new syntax. That's the challenge here, so the fundamentals need to be solid already.

2C is a sideways move, not a step up. The program itself is at the 2A level, because learning a new language is the stretch.

What You'll Build

A program from the problem menu (calculator-type tool, quiz engine, or simple tracker), written entirely in your new language, at the 2A level. Alongside it, you'll keep a translation log showing how each Python idea carries over.

Your hello world (CP1)

In your Unit 2 project folder, make two files:

index.html

<!DOCTYPE html>
<html>
  <head>
    <title>My Project</title>
  </head>
  <body>
    <h1>My Project</h1>
    <script src="main.js"></script>
  </body>
</html>

main.js

console.log("Hello, world!");
alert("Hello, world!");

Open index.html in your browser (double-click it in File Explorer, or right-click → Open with → Chrome). You should get a pop-up, and the message in the Console. Commit it. That's your CP1 hello world.

"Console program" in the browser: JavaScript in the browser doesn't have a terminal. Use prompt() for input and alert() or console.log() for output, or build a simple HTML page with an input box. Either is fine. Your design-cycle work is what's assessed, not how fancy the interface is.

When You're Stuck

  • Write it in Python first. Get it working, then translate one function at a time.
  • Use the official docs. For JavaScript, that's MDN.
  • Ask another 2C student. You're learning the same things at the same time.
  • Check the Console. JavaScript errors in the browser show up in the Console (F12), with the line number.

Done Looks Like…

Your program works as well as a strong 2A project, and your translation log shows you understand why the new language does things differently, not just that you found the right syntax.
