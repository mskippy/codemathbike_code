Unit 3 — Choice Project 2: Data & Structures

Working with more complex data — dictionaries, nested structures, simple file-based data — on a project you choose from a short menu: inventory system, gradebook, game leaderboard, or budget tracker. Same checkpoint rhythm as Unit 2, but with less scaffolding: a menu of options replaces a single guided prompt, and partway through, a classmate plays "client" and sends you a feature request you didn't see coming.

What You'll Be Doing

Lists and dictionaries, file I/O, breaking your program into functions, basic testing.

If you're moving faster, you'll also use built-in data structures where they fit, organize your project across multiple files, write self-documenting code, and triage and implement that mid-project change request — mirroring real client work.

What You'll Produce

Your app, plus a written response to the feature request.
