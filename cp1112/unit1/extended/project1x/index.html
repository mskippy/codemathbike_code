Project 1X — Shared Start

Same adventure-game world as the Core track, same basic shape — a character, a branching choice, a small explorable space, an inventory. The difference is the bar: this project asks for three things Core's version doesn't.

Requirements

  1. A character and a branching adventure — roughly Core's Projects 1A + 1B combined
  2. At least one function that returns a value the rest of your program actually uses
  3. Handles bad input gracefully — a non-numeric answer where a number is expected shouldn't crash your program
  4. A dictionary-based inventory, not a list — item name mapped to quantity or description

Bad-input handling and dictionaries are both new territory beyond 1.EXT.1/1.EXT.2 — the notebook includes a short primer on two viable approaches (try/except, or a validation loop).

Getting Started

Download the project notebook, save it into your 1_python_learning folder in your cloned repo, and commit once you've saved it.

Download Project_1X_Shared_Start.ipynb

Before you submit: test your bad-input handling on purpose — actually type letters where a number is expected, and confirm your program doesn't crash.
