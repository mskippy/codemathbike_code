Input/Output & f-strings

So far, every value in your programs has been typed directly into the code. Today your programs start listening: input() lets a person type something back, and f-strings are the clean way to weave that — or any variable — into a sentence.

What You'll Learn

  • input("prompt") — pauses your program, shows the prompt, and waits for the player to type something and hit Enter
  • f-strings — put an f before the opening quote and wrap variables in { } to drop them straight into a sentence
  • Type conversion — input() always hands back a string, so wrap it in int() or float() when you need a number
Watch out for: input() always returns a string, even if the player types 100. Add two un-converted inputs together and you'll get "10" + "5" → "105" instead of 15 — convert numeric input the moment you read it.
