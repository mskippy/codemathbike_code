Loops

Every program so far has run each line exactly once, top to bottom. Loops let you repeat a block of code — either a fixed number of times, or until something changes. This is where your programs stop feeling like a list of instructions and start feeling like actual software.

What You'll Learn

  • for loop — repeats a set number of times, using range(n) for the numbers 0 through n-1
  • while loop — repeats as long as a condition stays True, for when you don't know the count ahead of time
  • break — exits a loop immediately, even if its condition is still true
Watch out for: a while loop needs something inside it that eventually makes its condition False — forget to update that variable and you've built an infinite loop. If a cell seems frozen, that's almost always why.
