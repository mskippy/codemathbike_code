Lists & Strings as Sequences

Every variable so far has held exactly one value. A list holds many values in order, under one name — perfect for an inventory, a party roster, or anything else that grows over the course of a game. Strings turn out to behave a lot like lists too, once you know what to look for.

What You'll Learn

  • Lists — inventory = ["sword", "shield"], indexed from 0, looped over with for item in inventory:
  • .append() and len() — add an item, or count how many there are
  • Strings as sequences — indexing and slicing work the same way ("dragon"[0:3] is "dra"), but strings are immutable — you can't change one in place
Watch out for: indexing starts at 0, not 1 — on a 3-item list, list[3] is an IndexError, since the valid indexes are 0, 1, and 2.
