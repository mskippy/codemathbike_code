Operators & Expressions

Variables are only useful once you can do something with them. Today's about the operators that combine and compare values — the arithmetic you'd expect, plus a couple of Python-specific ones worth knowing early.

What You'll Learn

  • Arithmetic: + - * / (always gives a float), // (floor division), % (modulo — the remainder), ** (exponent)
  • Comparison: == != < > <= >= — each gives back a bool, which is exactly what feeds into next lesson's conditionals
  • Order of operations: same rules as math class — exponents, then *//////%, then +/- — use parentheses to force a different order
Watch out for: // and % are easy to mix up — // gives the whole number of times one value divides another, % gives just what's left over. Try saying out loud what real quantity each one represents if you're not sure which to use.
