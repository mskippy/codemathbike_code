Conditionals

Every program you've written so far runs the exact same way every time. Conditionals change that — your code can finally make decisions, which means Zara's story can actually branch.

What You'll Learn

  • if — runs a block of code only when a condition is True
  • elif / else — more conditions to check, then a catch-all; Python runs the first True branch and skips the rest
  • and / or / not — combine conditions (both must be true / at least one must be true / flip a bool)
Watch out for: = assigns a value; == compares two values. Mixing them up in a condition (if health = 100:) is actually a SyntaxError in Python — it won't run at all, which is a fast, loud signal once you know what that error means.
