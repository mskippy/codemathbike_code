Functions

You've been writing the same kind of code over and over — reading input, calculating damage, printing a message. Functions let you package that up once, give it a name, and reuse it — the first real step toward organizing a program instead of just writing it top to bottom.

What You'll Learn

  • def — creates a function; anything in parentheses is a parameter, a value the function needs from whoever calls it
  • return — sends a value back out; a function with no return gives back None
  • Scope — a variable created inside a function only exists inside that function
Watch out for: print()-ing inside a function shows something on screen, but doesn't give the calling code anything to work with afterward. If you need to use the result later, you need return, not just print().
