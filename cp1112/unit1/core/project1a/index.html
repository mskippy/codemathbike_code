Project 1A — Character & First Choice

Checkpoint 1 of 3. This is where the adventure game becomes your adventure game — everything from here builds on what you make today. Using only what 1.1–1.4 taught you, you'll create a character and give them one real decision to make. No new syntax today — this is about putting the last four lessons together into one working thing.

Requirements

  1. Four character variables — one each of str, int, float, bool
  2. At least one input() — the character's name is a natural fit
  3. At least one calculation using an operator
  4. An intro printed with f-strings, using your character's variables
  5. One branching decision (if/else or more) where the player's choice or a stat leads to genuinely different outcomes

Aiming higher? The notebook lists Tier 2 and Tier 3 stretch goals — comparison-based branching, a third outcome, and a choice that changes a stat afterward.

Getting Started

Download the project notebook — it includes a starter scaffold, not a blank page. Save it into your 1_python_learning folder in your cloned repo, and commit once you've saved it.

Download Project_1A_Character_and_First_Choice.ipynb

Before you submit: run your notebook top to bottom at least twice, choosing differently each time, and confirm you see every branch's outcome print correctly.
