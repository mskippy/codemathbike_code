Variables & Data Types

Welcome to Python Foundations. Every program starts the same way — giving names to pieces of information so you can use them later. That's a variable, and it's the first building block for everything else this semester, including the text adventure game you'll start putting together over the next few classes.

What You'll Learn

  • str (string) — text, always in quotes — character_name = "Zara"
  • int (integer) — a whole number, no quotes — health = 100
  • float (decimal) — a number with a decimal point — damage_multiplier = 1.5
  • bool (boolean) — exactly True or False, no quotes — is_alive = True

Python figures out the type automatically from the value you give it — you never have to declare it yourself. The built-in type() function tells you what type any variable actually is.

Watch out for: a string without quotes isn't text — Python will think it's another variable and crash. And True/False are capitalized with no quotes — true, false, and "True" are all something else entirely.
