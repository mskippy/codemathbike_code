Project 1A — Character and First Choice (Your Language)

Build the start of the adventure game in your approved language. The player creates a character and makes one choice that changes what happens next. The game's story is up to you; the goals below are not.

Goals: what this project shows, in any language

By the end of 1A, your code should show that you can:

  1. Store data in variables of at least four different types, for example text, a whole number, a decimal and a true/false value. Name each one clearly.
  2. Get input from the user and convert it to the type you need (for example, text to a number).
  3. Calculate something with a variable and a value, such as a starting health or gold total after a choice.
  4. Print a message that uses your variables, using your language's string formatting or joining method. Check your language's docs for how it's written.
  5. Make one branching decision with an if/else (or your language's equivalent) that changes the output.

What to Hand In

  • The program runs from start to finish, with at least two different choices tested
  • Concept-log rows for variables, input and output, operators, and conditionals
  • A commit with the prefix CP1:, pushed before your one-on-one

Every shared rule is on the Common Parameters card.

Getting Started

Start with a blank file in your language, in the 1_foundations/adventure_game folder. Write a hello-world line first and confirm it runs. Then build the goals above one at a time, and run the program after each one.

There are no Python lessons on this track. Your language's official documentation is your main reference.
