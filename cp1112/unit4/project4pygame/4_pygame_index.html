Setup

In the VS Code terminal, install pygame:

pip install pygame

Check it worked:

python -c "import pygame; print(pygame.version.ver)"

On a lab machine: if pip is blocked, tell your teacher during the proposal stage, so there's time to sort it out or pick another option.

A Starting Point

This opens a window and keeps it open until you close it. Build your game from here.

import pygame

pygame.init()
screen = pygame.display.set_mode((640, 480))
clock = pygame.time.Clock()

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((20, 20, 30))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

A pygame program redraws the screen many times a second. Keep your game logic in functions, and call them from the loop, rather than writing it all inside the loop.
